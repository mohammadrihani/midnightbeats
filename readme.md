# Midnight Beats
## Description
Midnight Beats is a responsive web application built using React(vite). It allows users to search music, find new songs and artists. 
It has a user-friendly and interactive interface to keep users engaged.
## Demo
https://midnightbeats.netlify.app/
## Technologies used:
React 
HTML
CSS
Javascript
Git & Github
Netlify (for deployment)
## Project Setup:
### Clone the repository
git clone https://github.com/mohammadrihani/midnightbeats.git
cd midnightbeats
npm install
npm run dev
